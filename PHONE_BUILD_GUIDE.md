# Phone-only APK build

Upload the contents of this project to a GitHub repository, preserving folders.

Then:
1. Open Actions.
2. Select **Build T&T Smart Learners APK**.
3. Tap **Run workflow**.
4. Wait for the green check.
5. Open the completed run.
6. Download **TT-Smart-Learners-APK**.
7. Install `app-debug.apk` on your phone.

Android Studio is not required. GitHub Actions installs Gradle and the Android SDK for the build.
